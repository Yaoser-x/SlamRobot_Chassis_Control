## 实验原理

### 1. PS2 通信协议

PS2 手柄使用类 SPI 协议（CLK/CMD/DAT/CS），GPIO bit-bang 实现：

| 信号 | STM32 引脚 | 运行时方向 |
|------|-----------|------------|
| CMD / PS2_DO | PE3 | 输出到手柄 |
| DAT / PS2_DI | PE2 | 从手柄输入 |
| CS | PE4 | 输出，低有效 |
| CLK | PE5 | 输出 |

```
帧长: 9 字节 (0x01 0x42 ...)
速率: ~50 kbps (CLK half-period = 10μs)
模式: 模拟模式 (0x73 / 0x79), 所有轴输出 0~255
```

初始化序列：
1. 短轮询 2 次（5 字节帧，不读回数据）
2. 进入配置模式 → 设置 analog + vibration → 退出配置
3. 确认手柄在 analog 模式

### 2. 摇杆映射与死区

摇杆原始值 0~255，中心点 128。归一化公式：

```
normalized = (raw − 128) / (127 − deadzone)   (正值)
normalized = (raw − 128) / (128 − deadzone)   (负值)
|raw − 128| ≤ deadzone → normalized = 0
```

默认死区 `PS2_AXIS_DEADZONE = 18`（约 ±14% 中心范围）。

| 控制轴 | 物理操作 | 映射 | 范围 |
|--------|---------|------|------|
| 左摇杆 Y | 前推/后拉 | linear_x (线速度) | ±0.5 m/s |
| 右摇杆 X | 左推/右推 | angular_z (角速度) | ±5.0 rad/s |
| 十字键 ↑↓ | 方向键 | linear_x = ±0.5 m/s | — |
| 十字键 ←→ | 方向键 | angular_z = ±5.0 rad/s | — |

### 3. 宏指令

肩键触发定时转弯宏（无需持续按住摇杆）：

| 按键 | 方向 | 持续时间 | 角速度 |
|------|------|----------|--------|
| **L1** | 左转 | ~1.57s (90°) | 5.0 rad/s |
| **R1** | 右转 | ~1.57s (90°) | 5.0 rad/s |
| **L2** | 左转 | ~6.28s (360°) | 5.0 rad/s |
| **R2** | 右转 | ~6.28s (360°) | 5.0 rad/s |

宏执行期间手动操作摇杆 → 自动取消宏。

### 4. 三角键巡线切换

三角键上升沿触发巡线启停切换（`PS2_LINE_TOGGLE_MASK = 0x10`）。切换后需要手动关闭巡线（再按一次三角键或 `line off`）。

### 5. 离线退让

连续 3 次读取失败（`PS2_OFFLINE_FAIL_LIMIT`）→ 手柄标记 offline → 清除 PS2 控制源 → 底盘停止。

### 控制源切换时序

从 CSV 日志的 `source` 字段观察多源切换事件：

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('lab07_source.csv')
t = df['t_ms'] / 1000.0

source_names = {0: 'NONE', 1: 'UPPER', 2: 'PS2', 3: 'ESP12F', 4: 'DEBUG', 5: 'LINE'}
transitions = df['source'].diff().fillna(0) != 0

plt.figure(figsize=(12, 4))
plt.plot(t, df['source'], 'b.-', markersize=2, alpha=0.7)
for idx in df.index[transitions]:
    plt.annotate(source_names.get(df['source'].iloc[idx], '?'),
                 (t[idx], df['source'].iloc[idx]),
                 fontsize=8, rotation=45)
plt.yticks(range(6), [source_names[i] for i in range(6)])
plt.xlabel('Time (s)')
plt.ylabel('Active Control Source')
plt.title('Control Source Arbitration Timeline')
plt.grid(alpha=0.3)
plt.tight_layout()
plt.savefig('lab07_source_arbitration.png', dpi=150)
```

## 常见问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 手柄在线但摇杆无响应 | analog 模式初始化失败 | 重新上电；检查接收器接线 |
| 摇杆释放后底盘不停 | 摇杆未归中或死区过小 | 检查摇杆物理回中；微调 `PS2_AXIS_DEADZONE` |
| `fail` 持续增长 | 信号干扰或距离过远 | 缩短接收器与手柄距离；检查 GPIO 上拉 |
| 释放摇杆后 source 不切换 | 另一源正在持续发送命令 | `status` 检查其他源的 `enable` 状态 |
