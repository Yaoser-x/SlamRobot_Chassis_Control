# 底盘业务契约与验收边界

本文件说明命令仲裁、传感器失效、后台维护和无线遥控的运行契约。
Upper Protocol v3 帧布局、物理串口、产品默认参数及已有硬件验收边界保持原定义。

## 命令与能力

- 控制模式与 capability mask 的交集决定允许来源。与当前模式无关的能力变化不撤销已接受命令；
  有效允许集合变化仅对变更来源设置 rearm。显式模式切换仍撤销旧来源，并要求新的合法意图。
- 巡线关闭期间仍采样并发布传感器有效性和新鲜度。第一次显式启用可使用已发布的可用性事实；
  传感器恢复不自行恢复巡线运动。
- wire session、sequence 和执行槽是不同状态。新控制意图推进 sequence；重复 UART 重传只有
  命中当前已接受命令的身份和刷新 token 才可续租，不能复活已撤销或超过最大寿命的命令。

## UART 接收

- Upper UART 的完整 28 字节控制帧和连续多帧可直接接收，不要求发送端拆包。
  RX 容量与溢出判断不使用下行遥测的最大帧长度。
- 512 字节循环 DMA 按实际 8N1 波特率计算安全轮询间隔，保留 10% 余量；115200 baud 时为 39ms。
  正常 Host 周期为 5ms。NDTR 只能表示环内位置，超过安全间隔时即使读写位置相等也丢弃歧义数据并重同步。
  间隔内先在短临界区复制待处理字节，再在临界区外解析，避免命令处理期间 DMA 复用原缓冲区。
- 主机回归覆盖整帧、448 字节突发、环边界、整圈及多圈丢弃、恢复、波特率和时钟回绕；
  物理验收还需在新固件上重复整帧／分段对照和真实 UART HIL。

GET_INFO 的 HELLO 请求在入发送队列前消费；队列拒绝、底层立即发送失败或 UART
错误恢复时保留重试请求。入队成功不等于发送完成，不能覆盖错误路径重新置位的请求。
主机回归注入 HELLO 的首次 HAL 发送失败，要求无需再次 GET_INFO 即可重试。
这证明候选源码的故障恢复行为，不表示已在板上烧录并通过实际 UART 复测。
2026-10-17 因操作者报告 PCB 焊接和树莓派供电问题，硬件联调暂停；修复供电后
重新确认身份、参数、架空和看护条件，再复测受影响的通信与停车场景。

## PS2 航向宏

- 启动前及运行期间均检查 IMU online、标定、质量和配置的新鲜度上限。失效时取消宏，
  使用已有 `RELATIVE_YAW_END_IMU_INVALID` 原因并在同周期提交零速。
- `StateEstimation_GetImuSampleSnapshot()` 原子复制 IMU 事实，返回 accepted sample generation。
  仅新的样本推进陀螺仪积分；重复快照不制造角度进度。宏启动前的样本不计入本次旋转。
- 原 `StateEstimation_GetImu()` 继续返回 sample 与 status 的聚合 generation。
  宏取消后的 IMU 恢复需要新的按键边沿，不能自行续跑旧宏。

## 维护和参数

- 显式手动维护仍先阻止新命令、停车，再验证所有启用轮静止。
- 首次 IMU 标定的后台保存使用 `AppMotionMaintenance_TryBeginStationary()`：先确认已静止及
  Motor 周期未进行，才获取维护所有权；获取后再次确认静止，再执行保存。运动中或周期进行中
  的预检查失败不改变命令门、模式、测试租约和电机输出；获取失败按 1s 退避重试。
- 整包参数校验对全部浮点字段检查 finite，再检查范围与关联约束。NaN、正负无穷均拒绝，
  不改变当前模型或 generation。Flash payload 的 CRC 正确也不能绕过语义校验。

## ESP 网页控制

- owner heartbeat 与速度 deadman 独立。页面持有有效摇杆手势时每 50ms 发送最新速度，
  位置不变也发送新意图；每条 WebSocket 速度样本推进 sequence，纯 UART keepalive 保留原序号。
- 松手、pointer cancel、窗口失焦、页面隐藏或 owner 丢失清除当前手势和请求。
  owner 恢复后必须重新操作摇杆，不能恢复旧速度。

## 验收证据

主机回归覆盖失效 IMU 宏取消、重复样本、后台保存预检查与退避、巡线/模式/命令组合、
全部浮点字段的非有限值及 CRC 正确的非法 Flash payload，以及网页固定手势、松手和控制权恢复。
主机测试与固件编译只能确认软件行为，不能证明真实 UART、PS2、IMU、电机或车辆已经通过验收。

下位机物理验收仍需独立完成：运行期 IMU 掉线/冻结、宏停车时延、静止自动保存与运动期间退避、
开机第一次巡线启用、固定无线摇杆持续控制与断联停车、参数掉电恢复，以及任务栈水位。
正式兼容、轮径/轮距和载荷控制效果继续以对应 HIL、标定及车辆证据为准。
