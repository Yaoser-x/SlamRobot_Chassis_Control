# 速度前馈与架空验证

`max_linear_mps` 和 `open_loop_full_mps` 仍为 0.5 m/s，约束业务命令及轮速目标。
PID 启用时，`pid_feedforward_full_mps` 单独定义速度到 PWM 的前馈标度，当前为
0.67 m/s。它是数学满量程 PWM 的参考标度，不是允许车辆以 0.67 m/s 行驶。

此前将目标 0.5 m/s 直接映射为 1000‰ 前馈，架空条件下存在明显超调。根据
150/250 mm/s 保持段的 PWM 和编码器速度，线性参考标度估计为约 0.65–0.69 m/s；
0.67 m/s 候选在同板架空对照中降低了超调。没有改变 PID 增益、速度斜率或参数
Flash 数据格式。

当新标度字段为零，或 PID 关闭时，保留原来的 `open_loop_full_mps` 映射；
原始 PWM 调试命令不经过此映射。轮速目标缩放继续使用原有 0.5 m/s 上限。

2026-10-13 架空实测：250 mm/s 前进的采样峰值从 282 降至 255 mm/s，倒车从
337 降至 253 mm/s。串口 ±500 mm/s 短时保持峰值为 512/514 mm/s，真实 PS2
前进/倒车复测峰值为 519 mm/s，未再出现加速后的意外停车。

这组标度依据现有编码器及轮径换算，并未构成地面里程或硬件最高速度标定。
后续需在落地负载与不同电池电压下重复起步、保持、回中及换向，核对轮径/
编码器换算、稳态误差、超调及左右一致性，再决定是否需要分电机或分方向标度。
