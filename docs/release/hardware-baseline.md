# F407 V2 硬件基线

硬件 identity 为 `0x00020000`，CubeMX 工程为 `F407_V2.0.ioc`，生成器版本 6.15.0。rc1 冻结不修改 `.ioc`、引脚、外设、任务周期或优先级。

协议轮顺序固定为 LF/LR/RF/RR，对应 M1/M2/M3/M4。默认实际驱动布局为 M2 左轮、M3 右轮，enabled mask `0x06`。禁用轮不参与侧观测、不置 speed-valid、不触发无反馈故障。运行时方向参数由固件统一应用；上位机不得二次翻转。

板级验收必须记录板卡版本、参数 CRC、手动正转 M2/M3 的协议符号、示波器证据及状态快照哈希。记录未齐全前仅为候选基线。
